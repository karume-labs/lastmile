# apps/staff-mobile

Mobile application for staff (Expo / React Native).

Overview

- Expo-based mobile app used by staff to manage deliveries and program operations.
- Uses `EXPO_PUBLIC_APP_URL`, shared auth, and API endpoints.

Getting started

- Install dependencies and run `expo start` from the app folder or workspace runner.
- Configure environment variables for the mobile client.

Development

- Use the Expo Go app or simulator to test flows.

Notes

- Keep mobile authentication origins and deep-links aligned with admin web and API settings.

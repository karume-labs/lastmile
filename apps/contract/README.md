# apps/contract

Contract-related tooling and CLI for Lastmile.

Overview

- Contains utilities and code related to smart contracts, transaction proofs, or contract deployment helpers used by the system.

Getting started

- Install dependencies at the workspace root.
- Review `package.json` in this folder for available scripts.

Development

- Typical tasks include building contract artifacts, running linters, and running any contract-specific tests.

Notes

- This app is mostly tooling-focused; confirm the target runtime (Node version) before running build scripts.
